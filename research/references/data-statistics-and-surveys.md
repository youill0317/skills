# Data, Statistics, And Surveys

Use this when evidence depends on official statistics, public datasets,
dashboards, benchmarks, survey estimates, administrative data, proprietary
estimates, models, app rankings, self-reports, forecasts, or vendor claims.

## Data Source Checks

- identify the source table, dataset ID, dashboard view, API endpoint, release
  date, data vintage, and whether later revisions supersede the cited value
- inspect methodology notes, data dictionaries, codebooks, variable definitions,
  universe/population definitions, denominators, weighting, seasonal adjustment,
  imputation, suppression, and uncertainty intervals
- check denominator, universe, geography, category, instrument, question wording,
  sampling frame, collection mode, or benchmark changes before comparing periods
  or jurisdictions
- distinguish raw counts, rates, indexed values, model estimates, projections,
  rolling averages, seasonally adjusted values, and preliminary versus final data
- preserve break-in-series notes, revision history, confidence intervals,
  margins of error, caveats, and proxy limits in the final answer
- prefer official tables, API metadata, codebooks, and release notes over
  dashboard screenshots or secondary chart copies

## Proxy And Method Caveats

- check sampling frame, denominator, geography, time period, measurement method,
  incentives, missing uncertainty, and validation
- separate direct measurement from proxy inference
- triangulate with independent source families when possible
- treat exact numbers as weaker when methodology is unpublished or opaque
