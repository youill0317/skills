# Evidence Needs Core

Use this to choose source families for a research question. Include every family
that could materially change the answer.

## Source Families

| Evidence Need | Strong Source Families | Checks |
|---|---|---|
| What is true or official | governing pages, filings, laws, standards, docs, primary records | authority, version, effective date, scope |
| What changed recently | changelogs, dockets, advisories, status pages, latest official updates, corrections | currentness, supersession, timestamp |
| What the literature says | papers, systematic reviews, methods, replication work, citations | method, sample, peer review, retraction |
| What the data shows | datasets, surveys, codebooks, tables, appendices, methodology notes | denominator, unit, geography, date, uncertainty |
| What could be wrong | criticism, failures, counterclaims, negative findings, disputes | directness, strength, relevance |
| Where a claim came from | original source, archive captures, source lineage, authors, funding, affiliations | incentives, manipulation, independence |
| How options compare | official specs, prices, benchmarks, reviews, procurement data, user reports | criteria, comparability, missing data |
| How it works technically | source code, commits, releases, issues, package registries, implementation docs | version, reproducibility, maintainer status |

## Evidence Strength

Prefer direct primary sources. Use independent corroboration when primary
sources are partial, conflicted, interested, or hard to interpret. Label weak
evidence instead of silently treating it as strong.
