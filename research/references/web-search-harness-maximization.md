# Web Search Harness Maximization

Use this when web, browser, source-open, archive, repository, PDF, or connector
search tools are available.

## Maximize The Harness

- Batch independent searches when the tool supports batching.
- Use diversified query families rather than keyword variants.
- Open or fetch high-value sources before using them as evidence.
- Use in-source search, PDF/document extraction, archive retrieval, repository
  browsing, and connectors when they are materially relevant.
- When a source is blocked, try authorized alternates: official mirrors, PDFs,
  archives, APIs, repositories, cached versions, cited excerpts, or browser
  access.
- Record unavailable or blocked capabilities as limits, then compensate with
  other authorized source families.

## Search Passes

Run passes that cover:

1. source-of-truth discovery;
2. currentness and supersession;
3. independent corroboration;
4. counterevidence and disagreement;
5. provenance and archive checks;
6. snowball leads from useful sources;
7. blocked-source recovery.

Search volume is not saturation. The record must show how the retrieved
evidence changed or constrained the answer.
